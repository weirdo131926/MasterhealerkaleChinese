## 安装

1. 下载本汉化 Mod 压缩包。
2. 将压缩包内的**全部文件**解压到游戏根目录。
3. 如果出现同名文件，选择**覆盖**。

### 游戏根目录示例

```text
...\steamapps\common\Master Healer Kale\Master Healer Kale\
```
